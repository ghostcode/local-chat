# 🗨️ LAN Chat

一个基于 Express + Socket.io 的轻量级局域网聊天应用。无需注册账号，输入昵称即可创建或加入房间，支持房间分享、在线成员列表、Emoji 表情、历史消息回溯等功能。

---

## 功能特性

- **创建/加入房间**：首页一键生成 6 位房间号，或直接输入已有房间号加入。
- **分享房间**：创建房间后自动生成分享链接，其他人点击链接即可加入。
- **昵称进入**：无需账号体系，输入昵称即可进入聊天。
- **实时消息**：基于 Socket.io 的 WebSocket 实时广播，延迟低。
- **在线成员列表**：右侧侧边栏展示当前房间在线成员。
- **Emoji 表情面板**：消息输入框支持表情选择。
- **历史消息**：新加入者自动获取最近 100 条聊天记录。
- **页面 URL 同步**：进入房间后浏览器地址自动变为 `room.html?room=XXXXXX`，刷新不丢失。
- **马卡龙配色**：Tailwind CSS 实现的柔和 UI 风格。

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 启动服务

```bash
node server.js
# 或
npm start
```

启动成功后会输出本机访问地址和局域网访问地址，例如：

```
本机访问: http://localhost:3000
局域网访问: http://10.0.129.23:3000
```

### 3. 使用

- 在浏览器中打开 `http://localhost:3000`。
- 输入昵称，点击「创建房间」生成新房间。
- 创建房间后可直接复制房间地址分享给朋友。
- 朋友打开链接后输入昵称即可加入同一房间。
- 也可以直接输入已有的 6 位房间号加入房间。

## 主要事件说明

| Socket.io 事件 | 方向 | 说明 |
|-----------------|------|------|
| `create-room` | 客户端 → 服务端 | 创建新房间 |
| `check-room` | 客户端 → 服务端 | 首页验证房间是否存在（不加入、不广播） |
| `join-room` | 客户端 → 服务端 | 真正加入房间，注册 socket，广播系统消息 |
| `send-message` | 客户端 → 服务端 | 发送聊天消息 |
| `room-info` | 服务端 → 客户端 | 广播当前房间用户列表 |
| `new-message` | 服务端 → 客户端 | 广播新聊天消息 |
| `system-message` | 服务端 → 客户端 | 广播系统提示（加入/离开/创建） |

## 注意事项

- 服务器默认监听端口 **3000**，可通过环境变量 `PORT` 修改。
- 房间在所有人离开后 5 分钟自动清理。
- 消息历史最多保留最近 100 条。
- 昵称最长 20 个字符，最少 2 个字符。
- 应用设计为局域网使用，未实现持久化数据库，所有数据保存在内存中。
